# Sales Forecasting & Demand Prediction

## Project Overview
This project focuses on analyzing historical sales data, identifying sales trends and seasonal demand patterns, and forecasting future sales to support business decision-making.

## Tools & Technologies
- Microsoft Excel
- Power Query
- Pivot Tables
- Excel Charts
- Forecasting and Time Series Analysis
- Data Visualization

## Project Workflow
1. Data Import – Imported the sales dataset into Excel.
2. Data Cleaning – Processed and prepared the dataset using Power Query.
3. Exploratory Data Analysis – Analyzed daily, weekly, monthly, and product-wise sales.
4. Trend Analysis – Identified growth, decline, and seasonal demand patterns.
5. Sales Forecasting – Used historical sales data to forecast future demand.
6. Dashboard Development – Created an interactive dashboard to visualize key business metrics.

## Key Analysis
- Overall sales and profit performance
- Daily, weekly, and monthly sales trends
- Product-wise sales performance
- Seasonal demand patterns
- Future sales forecasting
